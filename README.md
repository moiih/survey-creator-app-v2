# Survey Creator Web App

This is a web application primarily focused on allowing users to curste their own secure, clean and interactive online surveys 📊 with just few easy clicks. Yes, this might look *similar to Google Forms, but it is **certainly not at all copied and its 100% original work.***.
This website features community opinion polls, shareable surveys, results dashboard with organised statistics & graphs. The web app empowers users to create their own desired surveys and opinion polls with lots of customizations.

***Some major features are listed below:👇***

- Allows users to create surveys with questions in multiple styles/formats, e.g.:
  * ✅ Mutiple Choice Questions (MCQs) with ability to set correct option if the questions requires.
  * ✅ Questions which require text based response. In these type of questions too, the survey owner can predefine a correct text answer to match against the users' response if required.
  * ✅ Ability to an Image with any question to support the survey questionnaire.
- Community polls 📊 where any user can cat vote to any poll of her/his choice with results displayed instantly after the user has casted the vote.
- Allows users to share the surveys with a shareable 🔗link which can be easily generated for any survey.
- A dedicated 🎯Results Dashboard for Survey Owners to see the statistics and responses against their surveys with the availability of different graphs📈 for better understanding.

***Few attention to details things include:⏬***

- The web app scans every questions and analyses whether it is of interrogative-type or imperative-type:
  * 👉 If the Question is Interrogative and the user forgets to put a question marks at the end of the sentence, then web app automatically recognises it and adds a Questions Mark (❓) at the end.
  * 👉 If the Question is Imperative then it automatically recognises it and adds a colon(:) at the end of the sentence if the user has not used any other symbol.
- Have strictly isolated every user's profile and made sure that others private data is not visible and unaccessible on other users dashboard.
